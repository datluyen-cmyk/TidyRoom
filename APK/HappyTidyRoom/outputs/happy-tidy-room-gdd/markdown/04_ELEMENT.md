# Element

[← Mục lục GDD](GDD.md)

Chưa ghi nhận Element đặc biệt đang hoạt động để đưa vào thiết kế.

Element là cơ chế bổ sung làm thay đổi cách chơi hoặc tăng độ khó, như khóa hoặc bom. Layer, hộp nhận và slot chờ thuộc luật chơi cơ bản. Booster được mô tả riêng ở [05_BOOSTER.md](05_BOOSTER.md).
